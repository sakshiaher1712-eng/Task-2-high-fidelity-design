# CodeAlpha — Task 2: High-Fidelity UI Design

Project: StudyFlow Learning Dashboard

## Included
- `index.html` — self-contained responsive high-fidelity UI prototype (HTML, CSS, JavaScript).

## Run
Open `index.html` in a modern browser. No installation or internet connection is required.

## Features
- Responsive desktop and mobile dashboard
- Course progress cards and learning metrics
- Daily task checklist with interactive checkboxes and reset
- Sidebar navigation and mobile bottom navigation
- Weekly activity and streak cards
- Demo toast feedback for interactions

Note: This is a browser-based UI prototype, not an exported Figma/Adobe XD project.
